MY CHESS GAME - ANDROID PROJECT

This project wraps the supplied offline HTML chess game in an Android WebView.

Requirements:
- Android Studio
- Android SDK Platform 36
- JDK supported by your Android Studio/AGP version

Open this folder in Android Studio, sync Gradle, then build an Android App Bundle (.aab).
Application ID: com.example.mychessgame
Target SDK: 36
Version: 1.0 (versionCode 1)

Before Play Store publishing:
- Add a proper app icon
- Create screenshots and store listing
- Complete Play Console testing/Data Safety/app content requirements
- Sign the release AAB with a release key
